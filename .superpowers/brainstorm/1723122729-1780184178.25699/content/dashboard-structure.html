This layout gives us:

  • Sidebar: Navigation always visible, integration status always visible, brand identity clear
  • Topbar: Current page title + workspace context + user actions
  • Bento grid: 3-column responsive layout. Signal Orbit spans 2x2. Metrics, Pipeline, Signals, Drafts, Health in 1x1 slots
  • No emojis in icons — these are placeholders; we'll use lucide-react icons instead
  • Color-coded metrics: Green (success), Amber (pending), Cyan (active), Red (error)
