📐 Layout Architecture

  • Sidebar: 240px fixed width, collapsible on mobile, GitSync brand + 6 nav routes + integration status
  • Topbar: 56px fixed height, page title + workspace context + user menu
  • Main content: Bento grid responsive (3-col desktop, 2-col tablet, 1-col mobile)
  • Dashboard (/dashboard): Signal Orbit 2x2, Metrics 4x 1x1, Pipeline 2x1, Signals/Drafts/Health 3x 1x1

🎨 Typography & Fonts

  • Space Grotesk: All headings (h1, h2, h3, h4)
  • Plus Jakarta Sans: Body text, UI labels, buttons, navigation
  • JetBrains Mono: Code snippets, commit hashes, draft previews, audit logs
  • Pixelify Sans: ONLY status badges (SYNCED, REVIEW, FAILED, etc.) — nowhere else

🎭 Color Tokens & Usage

  • #0E1116 (--bg): Page background
  • #151A21 (--surface): Topbar, sidebar, secondary surfaces
  • #1E242D (--surface-soft): Card backgrounds, panels
  • #32D583 (--signal): Success, connected, synced, publish complete
  • #F5B544 (--commit): Pending review, in progress, warnings
  • #37D5FF (--cyan): Active, highlighted, AI-generated, sync in progress
  • #0A66C2 (--linkedin): LinkedIn publishing CTAs, LinkedIn-related actions
  • #F97066 (--danger): Errors, failed syncs, disconnected

🔧 21st.dev Patterns Adapted

  • Aceternity Sidebar: Persistent navigation with clear active state, collapsible on mobile
  • Bento Grid (Kokonutd): Responsive multi-column layout with CSS grid, adaptive spans
  • Animated Metric Cards: Quick stats cards with color-coded values and icons
  • Subtle motion: Smooth transitions on nav active state, card hover states (respects prefers-reduced-motion)
  • Card styling: Subtle borders, rounded corners, consistent padding/spacing
  • Status badges: Small, uppercase, monospace font, color-coded by state

✨ Key Visual Principles

  • ✓ High information density: No giant empty hero sections
  • ✓ Premium dark aesthetic: Technical cockpit feel, not generic SaaS blue
  • ✓ Clear hierarchy: Sidebar + topbar + content, not competing visual elements
  • ✓ Functional colors: Each color has a purpose (LinkedIn, signal, warning, error)
  • ✓ No placeholder UI: All pages are production-ready and useful
  • ✓ Responsive: Desktop sidebar, tablet/mobile drawer
  • ✓ Accessible: Lucide icons only (no emoji), proper contrast, keyboard navigation
  • ✓ Performance: Lazy-load heavy components (3D), no global animation loops
