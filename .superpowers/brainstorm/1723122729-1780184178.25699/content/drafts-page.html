Drafts appear here when GitSync detects meaningful GitHub activity.
Connect a repository to get started.
  • Status Tabs: All, Pending, Approved filter the queue
  • Draft Card: Title, source repo, status badge, preview text in monospace, creation time, character count, action buttons
  • Preview Styling: Left border accent (cyan), monospace font family for evidence
  • Action buttons: Review (green) / Reject (red) for pending, View (gray) for approved
  • Empty state: Explains how drafts appear, guides to next action
  • Status badges: PENDING REVIEW, APPROVED use Pixelify Sans
