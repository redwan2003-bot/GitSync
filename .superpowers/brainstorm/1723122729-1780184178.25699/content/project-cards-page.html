💡 Tip
Project cards are managed manually on LinkedIn. GitSync helps you draft and organize them here for easy copying.
  • Two-column layout: Left card list, right preview/copy interface
  • Card list: Search, selectable cards with tags, quick visual indicators
  • Preview section: Full LinkedIn-styled card preview, copy button, edit button
  • Info cards: Last updated, character count, metadata
  • Guidance: Explains the purpose (drafting helper, not auto-publish)
  • Empty state: Prompts to add first card with clear CTA
  • Tag badges: Color-coded by category (UI, BACKEND, FRONTEND, DATABASE)
